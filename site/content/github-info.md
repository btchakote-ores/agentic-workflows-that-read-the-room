## Recent GitHub Blog stories worth reading

Source: [GitHub Blog](https://github.blog/latest/)

- **Agent skills:** [Build once, run on any agent](https://github.blog/ai-and-ml/github-copilot/build-once-run-on-any-agent-a-practical-guide-to-agent-skills/) shows how to capture repeatable engineering work in reviewable files that teams can reuse across agents.
- **Agentic engineering:** [Beyond code generation](https://github.blog/ai-and-ml/github-copilot/beyond-code-generation-a-developers-guide-to-agentic-engineering/) walks through using GitHub Copilot to plan, write code, review changes, and investigate production issues.
- **Accessibility docs:** [Accessibility statements now have a home on GitHub](https://github.blog/open-source/maintainers/accessibility-statements-now-have-a-home-on-github/) explains how GitHub highlights `ACCESSIBILITY.md` files so maintainers can document goals, known barriers, and supported environments.
- **Git internals:** [Inside GitHub's new Git storage architecture](https://github.blog/engineering/architecture-optimization/inside-githubs-new-git-storage-architecture/) describes how GitHub is built so thousands of agents can push to a single repository at once.
